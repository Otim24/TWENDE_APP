# Twende App - Master Plan

## Structure
- **backend**: FastAPI application.
- **passenger_app**: Flutter application for passengers.
- **conductor_app**: Flutter application for conductors.
- **admin_dashboard**: React dashboard for admins.
- **docker-compose.yml**: Orchestrates the environment.

## Setup
1. Copy `.env.example` to `.env` and fill in the values.
2. Run `docker-compose up --build`.
